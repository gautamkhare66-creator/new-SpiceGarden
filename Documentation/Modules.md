# Modules

## Authentication
Registration, login, password hashing, session storage, logout, and customer/admin authorization.

## Menu
Database-backed GridView, category filtering, search, sorting, availability, and add-to-cart actions.

## Cart
Session cart with add, increase, decrease, remove, clear, item subtotal, and total calculations.

## Orders
Checkout creates the order and its line items in one SQL transaction. User order history and details are read from SQL Server.

## Reservation
Customers can submit a table reservation. Admins review and update appointment status.

## Admin
Dashboard summary, categories, menu management, orders, reservations, and users.
